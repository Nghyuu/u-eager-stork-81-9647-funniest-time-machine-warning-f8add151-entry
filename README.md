# Do Not Tell Yourself

One warning label for a time machine, written for the Funniest Time Machine Warning Label bounty. The hazard is meeting your own duplicate self mid-trip — and the label's own advice is the paradox: warning yourself about the warning is exactly what it forbids. It is written by `main.ts` to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
